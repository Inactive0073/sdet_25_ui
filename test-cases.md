# Практикум SDET: задание UI GlobalsQA BankingProject (XYZ Bank)

## TC-001 — Создание клиента (Add Customer)
**ID:** TC-001  
**Название:** Создание клиента с Post Code 10 цифр и First Name, сгенерированным из Post Code  
**Предусловия:** Открыта страница менеджера (`BASE_URL` из data/urls.py).

**Шаги:**
1. Открыть страницу менеджера (Bank Manager Login).
2. Нажать "Add Customer".
3. Сгенерировать Post Code — 10 цифр (см. алгоритм в utils).
4. Сгенерировать First Name из Post Code по алгоритму (разбить на 5 двузначных чисел, каждое -> буква через `value % 26`, 0->a, 1->b, ...).
5. Ввести First Name, Last Name (например, "TestLast") и Post Code.
6. Нажать кнопку "Add Customer".
7. Подтвердить alert и проверить текст alert содержит "Customer added successfully with customer id:`id`".

**Ожидаемый результат:** alert с текстом `Customer added` и клиент добавлен (его можно найти в Customers).

## TC-002 — Сортировка клиентов по First Name (A→Z и Z→A)
**ID:** TC-002  
**Название:** Проверка сортировки клиентов по First Name в обе стороны  
**Предусловия:** Доступен список клиентов (возможно, добавляем несколько клиентов программно в тесте).  
**Шаги:**
1. Открыть Manager → Customers.
2. Нажать на заголовок столбца "First Name" для сортировки A→Z.
3. Получить список видимых First Name из таблицы.
4. Проверить, что список отсортирован по возрастанию (A→Z).
5. Нажать на заголовок "First Name" снова для сортировки Z→A.
6. Получить список видимых First Name.
7. Проверить, что список отсортирован по убыванию (Z→A).

**Ожидаемый результат:** После первого клика список — сортирован по возрастанию, после второго — по убыванию.

## TC-003 — Удаление клиента (по имени, длина имени ближе к среднему)
**ID:** TC-003  
**Название:** Удаление клиента, имя которого имеет длину, наиболее близкую к среднему арифметическому длины всех имён  
**Предусловия:** В Customers минимум 3 клиента (если нет — тест добавляет нужных клиентов).  
**Шаги:**
1. Получить список First Name всех клиентов из таблицы.
2. Для каждого имени вычислить длину.
3. Найти среднее арифметическое длин.
4. Выбрать имя, длина которого ближе всего к среднему (при равенстве — первый по порядку).
5. Удалить этого клиента (кнопка Delete рядом с записью).
6. Получить обновлённый список First Name.
7. Проверить, что выбранного имени в списке больше нет.

**Ожидаемый результат:** Выбранный клиент удалён; его имя отсутствует в таблице.
